# Tsuzuki 1.4.0 для Android TV и телефона

Тот же Tsuzuki, что и на ПК: каталог Shikimori, трекер, сезоны, статистика, импорт, настройки
внешнего вида, **онлайн-просмотр Kodik** (озвучки и серии, авто-подбор токена) и «Продолжить просмотр».
Управление пультом. Этот же APK работает и на телефоне в альбомной ориентации;
для телефона с раскладкой под узкий экран есть отдельный проект `tsuzuki-phone-src`
(портрет и альбом, меню сверху).

## Установка на телевизор

Готовый файл — `Tsuzuki-TV-1.4.0.apk`. Варианты:

1. **Флешка.** Скопируй APK на флешку, вставь в ТВ, открой файловым менеджером (X-plore, FX File Explorer
   или встроенным) и нажми на файл. Телевизор попросит разрешить установку из неизвестных источников — разреши.
2. **Send Files to TV.** Поставь это приложение на телефон и на ТВ и перекинь APK по Wi-Fi.
3. **ADB** (если включена отладка): `adb connect IP-телевизора` и `adb install Tsuzuki-TV-1.4.0.apk`.

Значок Tsuzuki появится в списке приложений Android TV.

## Пульт

| Кнопка | Что делает |
|---|---|
| Стрелки | переход между карточками, кнопками и пунктами меню |
| OK | открыть / нажать / отметить серию |
| Долгое OK или «Меню» | отметить все серии до выбранной |
| Назад | предыдущий экран, на первом — выход |

Поиск: встань на поле поиска и нажми OK — появится клавиатура (или голосовой ввод, если он есть на пульте).

## Чем отличается от ПК

- **Онлайн-просмотр** есть: Kodik открывается внутри приложения (WebView). Серии с озвучками,
  автоподбор публичного токена и свой токен — как на ПК.
- **Блокировка рекламы** на ТВ недоступна: WebView не перехватывает сеть, поэтому вкладка
  «Блокировка рекламы» в настройках скрыта. На ПК и Linux она работает.
- **Свои файлы.** Папка выбирается системным окном Android. Серию играет установленный видеоплеер
  (VLC, MX Player, Kodi), а после возвращения Tsuzuki спросит, отметить ли серию. Если при выборе папки
  пишет, что окна выбора нет, — на ТВ его вырезал производитель: поставь файловый менеджер (например, X-plore).
- **Сервисы** (Кинопоиск, Okko, Wink и т.д.) открываются в своих приложениях на ТВ, если они установлены, иначе — в браузере.
- **Резервная копия и импорт MAL** — через системное окно выбора файла. Список удобно перенести с ПК:
  «Сохранить копию…» на ПК → флешка → «Загрузить из копии…» на ТВ.

## Как устроен проект

```
app/src/main/
  java/local/tsuzuki/tv/
    MainActivity.java     ← экран с WebView, кнопки «Назад» и «Меню»
    NativeBridge.java     ← замена Electron: данные, запросы к Shikimori/AniList, файлы, плееры
  assets/www/             ← интерфейс (копия src/renderer из ПК-версии + файлы ниже)
  AndroidManifest.xml     ← значок и баннер для ТВ-лаунчера
tv-web/
  android-api.js          ← window.api поверх Java-моста (тот же набор функций, что на ПК)
  tv-nav.js               ← навигация пультом
  tv.css                  ← рамка фокуса и прочие ТВ-стили
sync-www.sh               ← копирует интерфейс из ПК-версии в assets/www
app/tsuzuki.keystore      ← ключ подписи (пароль tsuzuki), нужен, чтобы обновления ставились поверх
```

## Как поменять и пересобрать

Интерфейс общий с ПК-версией. Порядок:

1. Правишь файлы в `tsuzuki/src/renderer` (ПК-версия) и проверяешь на компьютере (`npm start`).
2. `./sync-www.sh ../tsuzuki-src` — копирует интерфейс сюда (на Windows запускай в Git Bash).
3. `./gradlew assembleRelease` (на Windows `gradlew.bat assembleRelease`) →
   `app/build/outputs/apk/release/app-release.apk`.

Для сборки нужны JDK 17+ и Android SDK. Проще всего поставить Android Studio, открыть эту папку
и нажать Build → Build APK(s). Без Android Studio — создай файл `local.properties` со строкой
`sdk.dir=путь/к/Android/Sdk`.

Перед новой сборкой увеличь `versionCode` в `app/build.gradle`, иначе ТВ может не поставить обновление поверх.
