ЧТО НОВОГО В 1.6.0
------------------
Доделано автообновление (ПК + Android TV + телефон):

- **ПК:** приложение читает version.json (GitHub Releases), тихо качает установщик,
  **сверяет SHA-256** (подменённый файл не запускается), ставит только по https
  и только с разрешённых хостов.
- **Linux больше не пытается запустить .exe:** показывается «Доступна версия X»,
  кнопка «Скачать» открывает страницу релиза в браузере.
- **Выключатель «Проверять обновления автоматически» реально выключает** фоновую
  проверку и скачивание; ручная кнопка «Проверить обновления» работает всегда.
- **Экран «Обновления» в настройках:** текущая версия и все статусы
  («Проверяем…», «Доступна X», «Скачивается N%», «Готово — перезапустить»,
  «Ошибка»), кнопки «Перезапустить и обновить» / «Скачать».
- **После тихой установки Tsuzuki запускается сам**, а после запуска один раз
  показывает «Tsuzuki обновлён до X».
- **Android:** у ТВ и телефона теперь **разные адреса** version.json (чтобы телефон
  не «обновлялся» на ТВ-APK), SHA-256 APK проверяется в Java до открытия установщика.
- **Новый скрипт `Исходники\tsuzuki-src\tools\make-release.mjs`** — готовит папку
  `release/` (файлы с постоянными именами + три version.json с sha256) для GitHub Releases.
- Версия: ТВ versionCode 8, телефон versionCode 5.

3. В `Исходники\tsuzuki-tv-src\tv-web\android-api.js` ник тоже уже вписан

5. После публикации релиза обновления начнут работать автоматически.

ПРИМЕЧАНИЯ
----------
- Windows SmartScreen может предупредить (файл без подписи):
  «Подробнее» → «Выполнить всё равно».
- На Android блокировка рекламы недоступна (WebView), вкладка скрыта.
- AppImage для Linux на этой машине не собирался (нужен Linux и mksquashfs);
  портативный tar.gz — равнозначная замена.
- APK подписаны тем же ключом, что 1.4/1.5, поэтому обновляются поверх без удаления.
- Данные: Windows — %APPDATA%\Tsuzuki\tsuzuki-data.json,
  Linux — ~/.config/Tsuzuki/tsuzuki-data.json, телефон/ТВ — в памяти приложения.
- Политику конфиденциальности в docx и в приложении (views/privacy.js) правь вместе.
