ЧТО СДЕЛАТЬ ТЕБЕ — РЕЛИЗ И АВТООБНОВЛЕНИЕ TSUZUKI 1.6.5
=========================================================

Ниже — всё, что нужно сделать руками (регистрация, адреса, выпуск версий,
проверка на телефоне/ТВ). Пошагово, без спешки.

──────────────────────────────────────────────────────────────
ШАГ 1. GitHub: репозиторий Tsuzuki — сделать публичным
──────────────────────────────────────────────────────────────
Репозиторий уже создан: https://github.com/Svinota2/Tsuzuki
Но сейчас GitHub не отдаёт его без входа (значит, он ПРИВАТНЫЙ), а автообновление
скачивает файлы анонимно — из приватного репозитория не скачает.

1) Открой https://github.com/Svinota2/Tsuzuki и войди в аккаунт.
2) Settings → General → внизу «Danger Zone» → Change visibility → Make public.
   (Если боишься открывать исходники — создай отдельный ПУБЛИЧНЫЙ репозиторий
   только для файлов релиза, например tsuzuki-releases, и скажи мне: я переключу
   адреса и пересоберу приложение один раз.)
3) Пока репозиторий приватный/нет релиза, приложение в «Настройках → Обновления»
   пишет «репозиторий релизов не найден» — это нормально. После публикации релиза
   надпись сменится на «Установлена последняя версия».

ШАГ 4. Выпуск релиза (каждая новая версия)
──────────────────────────────────────────────────────────────
1) Подними версии:
   - Исходники\tsuzuki-src\package.json → "version" (например 1.7.0);
   - Исходники\tsuzuki-tv-src\app\build.gradle → versionCode +1, versionName;
   - Исходники\tsuzuki-phone-src\app\build.gradle → versionCode +1, versionName.
   (APPVERSION в установщике скрипт поправит сам.)

2) Собери файлы. Можно попросить меня — или сам:
   ПК:      cd Исходники\tsuzuki-src
            npx electron-builder --win dir --x64
            (затем установщик: makensis tools\build-installer.nsi)
   Linux:   npx electron-builder --linux dir --x64  + .deb/.tar.gz
   ТВ:      cd Исходники\tsuzuki-tv-src
            bash sync-www.sh
            gradlew assembleRelease
   Телефон: cd Исходники\tsuzuki-phone-src
            bash sync-www.sh ../tsuzuki-src ../tsuzuki-tv-src
            gradlew assembleRelease
   ВАЖНО: ключ подписи tsuzuki.keystore не менять и не терять —
   иначе Android не даст обновиться поверх старой версии.

3) Подготовь папку релиза:
   cd Исходники\tsuzuki-src
   node tools\make-release.mjs --repo "твой_ник/Tsuzuki"
   В папке release\ появятся 6 файлов:
     Tsuzuki-Setup.exe, Tsuzuki-TV.apk, Tsuzuki-Phone.apk,
     version.json, version-tv.json, version-phone.json
   (установщик и APK скрипт ищет рядом; пути можно указать явно
    ключами --setup, --tv, --phone; заметки — --notes "что нового").

4) GitHub → репозиторий Tsuzuki → Releases → Draft a new release:
   - Tag: v1.7.0 (номер как в package.json), Target: main;
   - перетащи ВСЕ 6 файлов из release\;
   - Publish release.
   После публикации ссылки .../releases/latest/download/version.json работают
   сразу — приложения увидят обновление при следующей проверке.

──────────────────────────────────────────────────────────────
ШАГ 5. Как проверить, что обновление работает
──────────────────────────────────────────────────────────────
- ПК: «Настройки» → «Обновления» → «Проверить обновления».
  Должно появиться «Доступна версия X» → «Скачивается N%» → «Готово — перезапустить».
  Нажми «Перезапустить и обновить» — установщик тихо обновит и запустит Tsuzuki,
  после запуска один раз появится «Tsuzuki обновлён до X».
- Телефон/ТВ: та же кнопка «Проверить обновления» (или через 15 сек после запуска).
  Скачается APK, откроется системный установщик. Первый раз Android спросит
  разрешение «Установка неизвестных приложений» для Tsuzuki — разреши.
- Без GitHub можно проверить локально (для разработки): положи version.json с
  version 9.9.9 на http://localhost, запусти приложение из исходников (npm start) —
  оно скачает файл, проверит SHA-256 и покажет плашку. Файл с неверным sha256
  не запускается.

──────────────────────────────────────────────────────────────
ШАГ 6. Что проверить на реальном телефоне/ТВ (я не мог — нет устройства)
──────────────────────────────────────────────────────────────
1) Уведомления о новых сериях: Android 13+ попросит разрешение при первом запуске;
   разреши, дождись проверки (раз в 6 часов) или нажми «Проверить сейчас».
2) Установка обновления: поставь старую версию (например 1.6.5), выложи json
   с versionCode 9, нажми «Проверить обновления» → «Скачать обновление» →
   должен открыться системный установщик.
3) Кнопка «Проверить обновления» на ТВ и телефоне должна брать СВОЙ APK
   (ТВ → version-tv.json, телефон → version-phone.json).

──────────────────────────────────────────────────────────────
ШАГ 7. Прочее
──────────────────────────────────────────────────────────────
- tsuzuki.keystore и пароль храни в двух местах. Потеряешь ключ — обновления
  APK не встанут, придётся удалять приложение у пользователей.
- GitHub может удалить репозиторий, если в приложении пиратские источники видео.
  Для такого случая лучше свой хостинг: тогда в settings.js добавь свой домен
  в UPDATE_ALLOWED_HOSTS (и в android-api.js), а адреса замени на свои.
- Цифры пользователей: https://eu.aptabase.com → приложение «Tsuzuki».
  Считаются только те, кто нажал «Разрешить» при первом запуске.
