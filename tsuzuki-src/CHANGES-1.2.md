# Tsuzuki 1.2 — что изменено

Версия 1.2.0, 02.11.2026. Сделано после проверки версии 1.1 на Windows.

Правки ограничены пунктами 2, 3 и 9 из списка пользователя, плюс два найденных
при тестировании дефекта. Ядро (Kodik, блокировка рекламы, трекер) не переписывалось.

## Пункт 2 — кликабельное название вместо текста

- `src/renderer/views/watch.js`: название тайтла в верхней панели онлайн-плеера
  теперь ссылка на страницу тайтла (`a.t.ttl`, подсказка «Открыть страницу тайтла»).
- `src/renderer/views/player.js`: то же для верхней панели плеера своих файлов
  (название серии/тайтла — кликабельно, ведёт на `#/anime/<id>`).
- `src/renderer/styles/app.css`: стили `.player-top a.t` (hover — акцентный цвет
  и подчёркивание).

## Пункт 3 — кнопки «Смотреть онлайн» заметнее

- Новый класс `.btn-online` в `app.css`: высота 46px, шрифт 15px/700, акцентный
  фон с лёгким градиентом, тень и подъём при наведении.
- Применён к кнопке «🌐 Онлайн с озвучками» в шапке страницы тайтла, к кнопке
  «▶ Смотреть онлайн» в блоке «Где смотреть» (`views/anime.js`).
- Причина отдельного класса: базовый `.btn` задаёт фиксированную высоту 36px,
  из-за чего кнопка выглядела мелкой.

## Пункт 9 — клик по серии открывает плеер и отмечает просмотренной

- `views/anime.js`: одиночный клик по номеру серии открывает онлайн-плеер на этой
  серии: `#/watch/<id>//auto/<серия>`.
- **Сопоставление сезонов:** у озвучки Kodik бывает несколько сезонов (в т.ч.
  сезон 0 — спешлы/бонусы), где серии нумеруются заново с 1. Поэтому плеер
  (`views/watch.js`) сам переводит плоский номер Shikimori в серию/сезон:
  - сезон 0 в нумерацию Shikimori не входит — считаем только основные сезоны (1, 2, …);
  - `auto/3` при структуре «s0: 1 серия + s1: 25 серий» откроет **S1E3**, а не s0e1;
  - если серия не нашлась — запасной поиск по номеру внутри сезонов.
- **Отметка** ставится уже в плеере, после того как серия реально найдена
  (а не по номеру из адреса) — так многiе сезонные озвучки не путают трекер.
- **Alt+клик** по серии отмечает/снимает отметку, не открывая плеер (возвращает
  возможность исправить ошибочную отметку).
- Двойной клик по серии по-прежнему открывает свой локальный файл (если папка выбрана).
- Правый клик по-прежнему отмечает все серии до этой включительно.
- Таймер отложенного клика (320 мс) отменяется при уходе со страницы.
- Подпись под блоком серий: «клик — смотреть серию, Alt+клик — отметить/снять,
  правый клик — отметить все до этой, двойной клик — свой файл».

## Исправлено при тестировании 1.1

- `src/main/adblock.js`: в фильтрах есть широкие правила `||yandex.net^`,
  `||mail.ru^`, `||rambler.ru^` — они блокировали не только рекламу, но и
  контентные CDN (например `avatars.mds.yandex.net`, картинки на страницах
  сервисов). Добавлен белый список контентных доменов (Kodik, Shikimori,
  AniLibria, YouTube, VK, Кинопоиск, IVI, Okko, Wink, Rutube, GitHub и др.),
  который проверяется раньше списка блокировки.
- `package.json` → версия 1.2.0.

- `USER_AGENT` обновлён до `Tsuzuki/1.2`.

- тема (dark → oled) применяется и сохраняется после перезагрузки;

- клик по серии на странице тайтла: переход в плеер, серия отмечена, 9 озвучек;
- Alt+клик по серии: отметка ставится/снимается, перехода нет;
- название тайтла в плеере — ссылка на страницу тайтла;
- кнопки онлайн — 46px, акцентные;
- регресс: Kodik-плейер, окно плеера через обёртку, 18+, удаление истории,
  adblock (13 запросов заблокировано на lenta.ru), склейка сезонов,
  статистика Shikimori, «Продолжить просмотр» — работают;
- ошибок в консоли нет.

## 1.2.1 — календарь, диалоги, логотип, обновление установщика

- **Календарь:** у всех тайтлов была одна и та же заглушка — REST `/api/calendar`
  Shikimori для многих записей отдаёт `missing_preview.jpg`. Теперь недостающие
  постеры дозапрашиваются через GraphQL (`getCalendar` → `getAnimesByIds`), иконки
  соответствуют названиям.
- **Диалоги подтверждения** вместо системных `window.confirm` — модальное окно
  в стиле приложения (история, удаление записей, сброс настроек, очистка данных,
  удаление своей записи). Enter — подтвердить, Esc/клик по фону — отмена.
- **Логотип Tsuzuki** в боковом меню — кликабельная кнопка «на главную» (`#/catalog`).
- **Установщик:** при повторном запуске распознаёт установленную копию
  (реестр/папка), обновляет её «на месте» без страниц приветствия и выбора папки,
  закрывает запущенный Tsuzuki по подтверждению (в тихом режиме — сам).
  Данные в `%APPDATA%\Tsuzuki` не трогаются. Версия 1.2.1.
