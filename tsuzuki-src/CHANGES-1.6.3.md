# Изменения 1.6.3 (07.11.2026)

Две вещи, которые оставались: статус в Discord при просмотре и отдельное
мини-окно плеера «как в Discord». Плюс статус для онлайн-просмотра (Kodik).

## Статус в Discord при просмотре

- **Онлайн-просмотр (Kodik, `views/watch.js`)**: в статусе теперь
  «название» и «Серия N из M» — как в плеере своих файлов. Раньше на странице
  онлайн-просмотра показывалось просто «В Tsuzuki».
- Обновляется при переключении серии/озвучки, убирается при уходе со страницы.
- Для фильмов — только название.
- Плеер своих файлов (`views/player.js`) — без изменений: «название · Серия N из M».

## Мини-плеер: отдельное окно «как в Discord» (ПК)

Новая кнопка **«⧉ В отдельном окне»** в плеере своих файлов открывает
отдельное окно (файлы: `main/mini-player.js`, `main/preload-mini.js`,
`renderer/mini.html`, `renderer/mini.js`, `renderer/styles/mini.css`).

- **Без рамки Windows**: нет заголовка и кнопок свернуть/закрыть; перетаскивать
  можно за верхнюю полосу.
- **Поверх всех окон** — булавка 📌 в окне переключает «поверх/обычно».
  По умолчанию поверх всех (`alwaysOnTop`, уровень screen-saver).
- **Минимализм**: только видео, при наведении появляются полосы — название
  с «Серия N из M», булавка, вернуть в основное окно, закрыть; внизу —
  перемотка, серия назад/вперёд, пауза, время, звук.
- **Синхронизация с основным плеером**: открыли мини-плеер — видео в основном
  окне ставится на паузу; переключили серию в мини-окне — основное окно
  переключается на неё же и обновляет статус Discord; закрыли мини-окно —
  основное окно продолжает с того же места и серии.
- Размер и положение окна запоминаются (`mini-window.json` в папке данных).
- Горячие клавиши: Пробел — пауза, ←/→ — перемотка, N/P — серия, M — звук,
  Esc — закрыть.
- Кнопка есть только на ПК (на Android и ТВ её нет — плеер там свой).

## Проверено

- ПК: окно мини-плеера открывается без рамки, кнопки «булавка/вернуть/закрыть»
  работают, данные для видео передаются; основной плеер ставится на паузу
  и продолжает после закрытия; остальные разделы без ошибок.
- Android: страницы в Discord нет (мобильный Discord не даёт статус приложений),
  мини-плеер только для ПК; оба проекта собираются.
- Discord «название + Серия N из M» — код общий с плеером (сборка строки
  `Серия N из M` в `main/extras.js`), отдельно проверить вживую без запущенного
  Discord нельзя.
