# Изменения 1.3.0 (07.11.2026)

Версия 1.3 — ядро доработок из «Промт-доработки-Tsuzuki.txt»:
задачи **0** (доделать переименование), **1** (синхронизация с Shikimori),
**2** (автообновление), **13** (анонимная статистика), **3** («Для тебя»),
**4** (фоновые уведомления и трей).
Задачи 5–12 («по желанию»: заметки, подборки, рулетка, папки, субтитры,
итоги года, Discord, достижения, Pro) — не делались.

## 0. Переименование — доделано

- Android: `applicationId` **оставлен прежним** (`local.anidesk.tv`), чтобы новая
  версия встала поверх старого AniDesk-TV и данные не потерялись; на экране
  и в лаунчере — «Tsuzuki» (android:label).
- Перенос данных на Android: `NativeBridge.dataFile()` при первом запуске копирует
  старый `anidesk-data.json` → `tsuzuki-data.json` (старый файл не удаляется).
- Баннер ТВ и иконки перерисованы в стиле Tsuzuki (тёмный фон #0F1115, ромб #FF5D48).
- `USER_AGENT` обновлён до `Tsuzuki/1.3 (anime tracker)` на ПК и Android.

## 1. Двусторонняя синхронизация с Shikimori

- Вход по OAuth2: кнопка «Войти через Shikimori» (ПК), на ТВ/телефоне — вход по коду
  (ссылка открывается на телефоне, код вводится в настройках).
- Токены хранятся отдельно от списка: на ПК — зашифрованными через `safeStorage`,
  на Android — в `SharedPreferences`. Автообновление по `refresh_token` при 401.
- Синхронизация: очередь локальных изменений (`store.syncQueue`), отправка пачками
  с паузами, приём постранично (`/api/v2/user_rates`), конфликты — по `updated_at`.
- Shikimori хранит только число серий: при отправке считаем максимальный подряд
  просмотренный номер, при получении отмечаем 1..N.
- Когда синхронизируется: при запуске, раз в 15 минут и через ~3 секунды после
  последнего изменения. «Синхронизировать сейчас» — в настройках.
- В карточке записи хранятся `shikiRateId`, `shikiUpdatedAt`, `rewatches`.
- Свои записи (manual) не отправляются.

**Настройки:** `src/main/settings.js` → `SHIKIMORI_CLIENT_ID`, `SHIKIMORI_CLIENT_SECRET`.
На Android — те же два значения в `tv-web/android-api.js`.

## 2. Автообновление

- Своё, без сторонних библиотек (наш установщик умеет обновлять на месте).
- Приложение читает `version.json` (адрес — `settings.UPDATE_JSON_URL`):
  `{ "version": "1.3.0", "url": "…/Tsuzuki-Setup-1.3.0.exe", "notes": "что нового" }`.
  Если версия новее — тихо скачивает установщик и показывает плашку
  «Обновление X скачано — перезапустить?»; установщик запускается в тихом режиме.
- Проверка при запуске и раз в 6 часов; можно выключить в настройках
  («Внешний вид и поведение» → «Система» → «Проверять обновления автоматически»)
  или проверить вручную: «Настройки» → «Обновления».
- Android: проверка `version.json` для APK (адрес — `UPDATE_URL` в `android-api.js`);
  если новее — показывается сообщение и открывается ссылка на скачивание.

## 13. Анонимная статистика (по желанию пользователя)

- `api/telemetry.js` — единственное место, откуда уходит статистика.
- При первом запуске — короткий экран «что отправляется» с кнопками
  «Разрешить» / «Не отправлять». Пока не выбрано — ничего не уходит.
- Отправляется раз в сутки: случайный `installId` (UUID), версия, платформа,
  язык, число тайтлов (округлённое до десятков). Ничего личного.
- Переключатель: «Настройки» → «Конфиденциальность»; дублируется в
  «Внешний вид и поведение» → «Система». Кнопка «Сбросить идентификатор».
- Адрес сервера — `settings.TELEMETRY_URL` (по умолчанию пуст = выключено).
  Можно указать свой счётчик (Cloudflare Worker и т.п.) или прокси Aptabase.
- Политика конфиденциальности обновлена: убран пункт «не собирает статистику»,
  добавлен раздел 5 «Анонимная статистика» и абзац про вход в Shikimori.

## 3. «Для тебя» — рекомендации

- Новый раздел `views/discover.js`, маршрут `#/discover`, пункт меню «Для тебя».
- Профиль вкуса: жанры и студии тайтлов с оценкой ≥ 8 (вес = оценка − 5);
  если оценок мало — «Просмотрено» и «Смотрю».
- Кандидаты: похожие с Shikimori для любимых тайтлов (`/api/animes/:id/similar`),
  топ по любимым жанрам, тайтлы любимых студий.
- Убираются: уже в библиотеке, скрытые кнопкой «Не интересно», клипы/промо,
  анонсы, без постера, с рейтингом ниже 6.
- Кеш на 24 часа в данных приложения, кнопка «Обновить подборку».
- Под каждой карточкой — причина («Похоже на «Фрирен»», «Твой жанр: драма»).

## 4. Уведомления о новых сериях и трей

- ПК: значок в трее (Открыть / Проверить новые серии / Выход), сворачивание
  в трей при закрытии (настройка), автозапуск с системой (настройка;
  на Linux — файл автозапуска, на Windows — реестр).
- Фоновая проверка онгоингов из «Смотрю»/«В планах» раз в 6 часов
  (`settings.NOTIFY_INTERVAL_HOURS`), даже если окно закрыто: системное
  уведомление «Tsuzuki — новая серия», клик открывает страницу тайтла.
- Android: уведомления о новых сериях — **не сделаны** (см. «Что осталось»).

## Что осталось / не проверено

- Вход в Shikimori: нужны `client_id`/`client_secret` от твоего OAuth-приложения —
  без них кнопка показывает пояснение. Реальный вход и синхронизацию надо
  проверить на настоящем аккаунте.
- Автообновление: нужно выложить `version.json` и новый установщик по HTTPS —
  без этого проверка сообщает «не настроено».
- Android: WorkManager-уведомления и установка APK из приложения не сделаны
  (проверка обновлений есть, установка — вручную через файл).
- Задачи 5–12 из файла («по желанию») не делались.
