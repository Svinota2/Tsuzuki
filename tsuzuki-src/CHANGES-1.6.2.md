# Изменения 1.6.2 (07.11.2026)

## Статус в Discord во всём приложении (ПК)

Раньше статус был только во встроенном плеере своих файлов. Теперь он показывает,
что ты делаешь в Tsuzuki:

| Где ты | Статус |
|---|---|
| Каталог | «Ищет аниме» · Каталог |
| Страница тайтла | «Выбирает, что посмотреть» · название тайтла |
| Библиотека | «Разбирает свой список» · Смотрю / В планах / … |
| История, календарь, статистика, итоги года, «Для тебя», люди | свои подписи |
| Плеер своих файлов | название · «Серия 5 из 12» (как раньше, важнее всего) |
| Остальное | «В Tsuzuki» |

- Новый файл `src/renderer/api/presence.js`: подписи разделов (функция `describe` —
  меняй слова там), приоритет плеера, лимит Discord (не чаще раза в 4,5 с,
  быстрые переходы склеиваются), мгновенное применение настроек.
- `app.js` сообщает о каждом открытом разделе; `views/player.js` шлёт статус через
  presence.js и после выхода из плеера возвращает статус раздела.
- `src/main/extras.js`: `setPresence` принимает и статус раздела (`kind: 'browse'`);
  строки короче 2 символов не отправляются (Discord такие отклоняет).
- Настройки: «Статус в Discord (ПК)» + новый пункт «Показывать в статусе Discord,
  что открыто в приложении» (`DISCORD_PRESENCE_BROWSE`, по умолчанию включён;
  выключен — статус только в плеере).
- Политика (раздел 2) обновлена: что именно видно в статусе и как это выключить.
- Проверено с имитацией Discord: все разделы, плеер → раздел, выключение пунктов,
  лимит при быстрых переходах.

## Ползунки в настройках больше не «трясутся»

- Причина: на каждое движение ползунка настройки целиком записывались на диск,
  а «Масштаб интерфейса» и «Ширина бокового меню» сразу меняли окно — ползунок
  уезжал из-под мышки, и значение прыгало (автотест: 80 → 130 → 80… 12 раз за одно движение).
- Теперь (`views/settings.js` → `onOption`): пока тянешь — только подпись и лёгкий
  предпросмотр (размер карточек, скругление); сохранение, масштаб и ширина меню —
  когда отпустишь. Автотест: значения идут ровно, 0 скачков назад.
